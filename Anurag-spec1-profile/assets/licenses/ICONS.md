# Icon and font sources

- Tech marks (Kotlin, OpenJDK used for "Java", Android, Jetpack Compose, Flutter, Go, Firebase, Docker,
  PostgreSQL, Redis, MongoDB, Prometheus, Grafana, Git, Google Play, Gmail): Simple Icons v16.35.0,
  CC0-1.0, https://simpleicons.org. Brand marks remain trademarks of their owners.
- LinkedIn tile: Simple Icons no longer ships a LinkedIn mark, so the card uses a plain blue tile with
  the letters "in" set in Barlow Condensed. Swap in the official asset from
  https://brand.linkedin.com if you prefer.
- Globe, pin, briefcase, graduation cap, people and cloud glyphs: drawn for this profile.
- Fonts embedded as base64 WOFF2: Barlow, Barlow Condensed, JetBrains Mono (SIL OFL 1.1, via Fontsource).
  Licence texts are in this folder.
